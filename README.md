# AI Action Plan

This folder contains a static website ready to publish with GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the files in this folder (`index.html`, `.nojekyll`, and this README) to the repository's root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. After GitHub finishes publishing, copy the site URL shown in **Settings → Pages** and share it.

The worksheet stores entries in each visitor's own browser. Responses are not shared between visitors or saved to a central service.
